# 🚀 Full Stack Development — Experiment 4

A full-stack web development project created as part of the **Full Stack Development** practical coursework. This experiment demonstrates the implementation of a web application using modern frontend and backend development concepts.

---

## 📌 Project Overview

This experiment focuses on understanding the development workflow of a full-stack application, including project structure, application logic, user interaction, and communication between different application components.

The project provides practical experience in developing, running, testing, and managing a web application using modern development tools.

## ⚙️ Prerequisites

Make sure the following are installed:

* **Node.js**
* **npm**
* **Git**
* **VS Code** or another code editor

Check Node.js:

```bash
node --version
```

Check npm:

```bash
npm --version
```

---

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

If the project uses Vite:

```bash
npm run dev
```

If the project uses Create React App:

```bash
npm start
```

Follow the URL displayed in the terminal to open the application.

---

## 🧪 Testing

Run the available tests using:

```bash
npm test
```

For a production build:

```bash
npm run build
```
